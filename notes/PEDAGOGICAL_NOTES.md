# Pedagogical Notes: Context-Space TDVP / Stochastic Reconfiguration

## 1. The basic variational picture

Consider a normalized neural quantum state

`|psi(M)>`,

where the large transformer weights are fixed and only a small real vector `M` is allowed to vary.

For a small time step,

`|psi(M + dt Mdot)> = |psi(M)> + dt sum_a Mdot_a |partial_a psi> + O(dt^2)`.

Exact quantum mechanics gives

`exp(-i H dt)|psi> = |psi> - i dt H|psi> + O(dt^2)`.

TDVP chooses `Mdot` so that the tangent vector generated by changing `M` is as close as possible to the exact Schrodinger tangent vector, after removing the physically irrelevant global-phase direction.

## 2. Log-derivative form

For basis configuration `sigma`, define

`O_a(sigma) = partial_{M_a} log psi(sigma; M)`.

Then expectation values over `|psi|^2` turn the tangent-space least-squares problem into the SR system

`S Mdot = F`,

where

`S_ab = Re <(O_a-<O_a>)^* (O_b-<O_b>)>`

and

`F_a = Im <(O_a-<O_a>)^* (E_loc-<E_loc>)>`.

The imaginary part in `F` is the real-time counterpart of the energy-gradient force used in imaginary-time/ground-state SR.

## 3. Why centering is important

Subtracting `<O_a>` removes the component associated with normalization and global phase. It makes `S` the pullback Fubini-Study / quantum geometric metric for the physical state manifold rather than the raw Hilbert-space metric.

## 4. Tangent coverage

Let the optimal projected tangent residual be `R`. The exact physical tangent has squared norm

`Var(H) = <H^2> - <H>^2`.

A useful dimensionless diagnostic is

`coverage = 1 - ||R||^2 / Var(H)`.

Interpretation:

- near 1: the context tangent space contains almost all of the instantaneous physical direction;
- near 0: changing only `M` cannot follow the Schrodinger direction;
- decreasing coverage can signal that the trajectory is leaving the learned manifold.

Coverage is local. High local coverage does not guarantee long-time fidelity because integration errors and manifold curvature can accumulate.

## 5. Effective context dimension

The eigenvalues of `S` tell us how many directions in context space actually change the physical state. Many raw context coordinates may correspond to nearly null physical directions.

Useful diagnostics:

- eigenvalue spectrum of `S`;
- numerical/effective rank;
- condition number of the active subspace;
- participation-ratio effective rank;
- overlap of `Mdot` with weak-eigenvalue directions.

This lets us distinguish raw latent dimension from physical manifold dimension.

## 6. Rende/sample-space SR identity

If the number of context parameters `P` becomes larger than the number of Monte Carlo samples, directly forming a `P x P` SR matrix is wasteful.

For a complex wavefunction, construct a real sample Jacobian matrix `X` of size roughly `P x (2 Ns)`. Then

`S = X X^T`.

Using the push-through identity,

`(X X^T + lambda I)^(-1) X = X (X^T X + lambda I)^(-1)`,

one can solve in sample space instead of parameter space. This is the main computational idea in the included Rende et al. paper.

Use the parameter-space solve when `P` is small; use sample-space SR when `P >> 2 Ns`.

## 7. Control-affine latent dynamics

If

`H = H0 + sum_mu h_mu H_mu`,

then the local energy and TDVP force are linear in the controls. Since `S` depends only on the current variational state,

`Mdot = f0(M) + sum_mu h_mu f_mu(M)`.

This gives a controlled latent ODE with physics-determined vector fields. It is an important structural property to verify numerically.

## 8. Finite-step projection versus SR

An alternative is to choose `Mdot` or `M_next` by directly minimizing the distance between

`exp(-iH dt)|psi(M)>`

and

`|psi(M + dt Mdot)>`.

This is a finite-step projection onto the curved manifold. SR is its infinitesimal tangent-plane limit. The two should agree as `dt -> 0`. Comparing them is an excellent numerical validation.

## 9. Common numerical pitfalls

- Wrong sign in the real-time force `F`.
- Forgetting centering of log derivatives.
- Treating complex context coordinates without a consistent real-coordinate convention.
- Inverting near-null eigenvalues of `S` without regularization/cutoff.
- Confusing local tangent coverage with accumulated global fidelity.
- Comparing models with different decoder capacity while claiming a context-only effect.
- Hard-normalizing each context token without enforcing the corresponding tangent constraint `M dot Mdot = 0`.
- Using too large a time step and attributing integration failure to insufficient expressivity.
